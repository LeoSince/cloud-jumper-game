云朵小勇士 v56：共享账号、排行榜、Gemini 智能聊天与上线状态设置（只需做一次）

共享账号、全部玩家排名、两周冠军、金币礼物、金币明细和公共聊天室都使用同一个 Cloudflare Workers KV。

设置方法：

1. 在 Cloudflare 控制台打开「存储和数据库」→「Workers KV」。
2. 新建 KV 命名空间，名称可填写：cloud-jumper-leaderboard。
3. 打开 Pages 游戏项目 →「设置」→「绑定」→「添加绑定」→「KV namespace（KV 命名空间）」。
4. Variable name（变量名称）必须填写：LEADERBOARD（全部大写）。
5. 选择 cloud-jumper-leaderboard，保存后重新上传 v56 网站 ZIP 部署一次。

检查方法：

- 打开 https://你的游戏网址/api/health
- kvBound:true 表示账号、排行榜与聊天存储已经绑定。
- 打开 https://你的游戏网址/api/leaderboard
- shared:true 表示全站共享排行榜可用。

赛季规则：

- 每个赛季为 14 天，系统会在赛季结束后的下一次访问时自动结算，不需要定时任务。
- 排名综合计算单人闯关关卡、分数和好友对战成绩；页面也可单独查看闯关排名与对战排名。
- 第一名会获得哆啦A梦冠军专属购买资格，资格跟随云端账号，换设备登录后仍可恢复。
- 排行榜会显示所有已注册账号和当前使用人物，不只显示前 10 名；金币是否公开由玩家自己决定。
- 玩家也可以选择是否公开上线状态：头像右上角绿色表示在线、蓝色表示一天内上线、红色表示超过一天；公共页面不返回精确时间。

注意：

- 不需要 GitHub，也不要手动修改 KV 内容。
- ZIP 根目录的 _worker.js 负责账号、排行榜、聊天、后台和好友对战连接，不能删除。
- 管理后台地址是 https://你的游戏网址/admin，默认密码 2026。
- 更新 v56 会继续使用现有 LEADERBOARD KV，不会清空账号、金币、排行榜或聊天记录。
- v56 会在部署后的首次排行榜访问自动扫描全部注册账号，之后每 5 分钟允许自愈扫描；后台“修复玩家列表”可随时强制补回遗漏账号。
- 赛季切换、清空赛季成绩或单独清除成绩只会把成绩归零，已注册账号仍显示“已登记 · 尚未挑战”。
- v56 继续防止重复刷新造成云端奖励或限量人物购买重复扣款；后台也可以使用“校正余额”准确修改单个玩家的金币而不清除其他进度。
- v56 的金币余额带云端版本号；旧页面和旧设备不能把管理员已经校正的余额改回去。
- 管理后台会显示每个真人玩家的精确最后活动时间和当前在线人数，不受玩家公开开关影响。
- 后台“运营控制”可以临时封锁玩家端并设定自动恢复时间，封锁和限量活动记录也保存在同一个 LEADERBOARD KV 中。
- 哆啦A梦只向赛季冠军开放专属购买资格，价格会在“赛季规则”和最终购买确认时显示。
- 后台新增兑换码管理：可设置金币和人物奖励、开始与截止时间、启用、停用和删除；每个账号对同一兑换码只能领取一次。
- 每日签到使用服务器的新加坡日期，同一天刷新或换设备都不能重复领取。
- 登录状态恢复和排行榜读取保持只读，连续刷新不会再产生重复账号写入。

推荐：接入 Gemini 免费智能回复

1. 打开 https://aistudio.google.com/apikey，用 Google 账号登录。
2. 点击「Create API key（创建 API 密钥）」；选择现有项目或创建新项目。
3. 复制生成的密钥。不要把密钥发到聊天、写进 game.js 或上传到 GitHub。
4. 打开 Cloudflare → Workers 和 Pages → leo-mario →「设置」→「变量和机密」。
5. 新增加密机密：名称必须是 GEMINI_API_KEY，值粘贴刚才的密钥。
6. 保存后重新部署 v56。默认先使用 gemini-3.6-flash；额度不足或模型暂不可用时会自动尝试 gemini-3.5-flash 和 gemini-3.5-flash-lite。
7. 打开 /api/health，geminiConfigured:true 表示 Cloudflare 已读到密钥。
8. 在聊天室发送“@小砚 admin：介绍 Gemini”，然后再次打开 /api/health；geminiLastCheck 中 ok:true、status:200 表示 Gemini 真正回答成功。

- Gemini API 密钥只在 Cloudflare 服务端使用，浏览器和玩家无法读取。
- v56 优先使用 Gemini 3.6 Flash；备用模型也不可用时才会退回本地安全回复。已经删除 OpenAI 变量也不会影响聊天。
- 没有密钥、免费额度用完、请求超时或接口暂时不可用时，会自动回退，不影响聊天发送。
- 普通 @任意挑战者会使用 Gemini，但会像真人一样等待约 18–65 秒；“@挑战者 admin：问题”会立即叫回。
- 没有 @时挑战者只会低概率接话；五个角色各自研究不同游戏机制，也能在玩家先提起时自然聊生活话题。
- 智能回复必须围绕玩家本句话的主题；“刚上线、准备玩第 5 关、先学路线”等无关回答会在发送前被拦截，并换成针对当前问题的安全回复。
- 真人刚发消息后的 2 分钟内，预排的挑战者日常闲聊会自动让路，避免看起来像是在错误回答真人。
- “好、嗯、知道了”等短回复会自然接话；“介绍 OpenAI / Gemini”等基础问题即使两个云端接口都失败，也有可读的本地答案。
- /api/health 只显示安全状态，不会显示 Gemini/OpenAI 密钥或聊天内容。

v56 管理员说明：

- 最高管理员仍使用后台密码 2026。
- 后台「管理员」页面可把真实注册账号设为管理员或取消权限；授权状态保存在 LEADERBOARD KV。
- 被授权账号使用普通游戏登录令牌进入后台，不会接触最高管理员密码。
- 管理员在聊天室长按任意消息即可进入多选，再点击其他消息批量永久删除；普通玩家看不到管理工具，长按只能撤回本人 5 分钟内的消息并保留“消息已撤回”记录。
- 后台「AI 助手」使用 GEMINI_API_KEY，AI 对话不写入公共聊天室或玩家数据。
