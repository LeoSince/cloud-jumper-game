云朵跳跳王：不用 GitHub，直接上传 Cloudflare

一、上传网站

1. 登录 Cloudflare，打开「Workers 和 Pages」。
2. 如果是新网站：点击「创建应用程序」→「Pages」→「拖放文件」。
3. 如果游戏网站已经存在：进入该项目 →「部署」→「创建新部署」。
4. 上传 v-56.zip。
5. 选择「生产环境」，点击「保存并部署」。

二、创建并绑定排行榜 KV

1. Cloudflare 左边进入「存储和数据库」→「Workers KV」。
2. 创建实例，名称填写：cloud-jumper-leaderboard
3. 回到游戏 Pages 项目 →「设置」→「绑定」→「添加」→「KV namespace」。
4. Variable name 必须填写：LEADERBOARD（全部大写）。
5. KV namespace 选择：cloud-jumper-leaderboard
6. 保存后回到「部署」，重新部署刚才的 ZIP，让绑定生效。

三、检查

打开：https://你的游戏网址/api/leaderboard

成功时会看到："shared":true
如果看到："shared":false，说明 KV 没绑定成功或绑定后还没有重新部署。

四、打开管理后台

1. 访问：https://你的游戏网址/admin
2. 默认管理密码：2026
3. 可以搜索玩家、归零单人成绩、删除并远程重置玩家、赠送金币、准确校正余额、修复玩家列表、导出 CSV 名单和清空赛季成绩。
4. 「删除并重置」会在该玩家下次打开首页、刷新排行榜或结束一局时执行，金币、已购人物、关卡和生命升级都会回到初始状态。
5. 如果以后想换密码，可在 Cloudflare 项目变量里添加 ADMIN_PASSWORD，它会覆盖默认密码。

五、玩家跨设备账号

1. v56 部署后，所有玩家必须先注册或登录。
2. 注册时输入玩家名称、密码和确认密码；当前设备的金币、人物、关卡和生命升级会上传到云端。
3. 换手机或电脑后，点击「已有账号登录」，输入相同名称和密码即可恢复记录。
4. 密码使用随机盐和 PBKDF2 哈希存储，不会以明文保存。
5. 玩家可在首页打开或关闭「公开金币」；关闭后公共排行榜不会返回金币数量。
6. 登录后点击首页右上角头像，可以修改头像、名称和肤色；修改名称后，下次要使用新名称登录。
7. 排行榜头像可以点击，能查看玩家正在使用的人物、已拥有角色、肤色与公开成绩。
8. 玩家可在右上角头像 → 个人中心选择是否公开上线状态；绿色圆点表示在线、蓝色表示一天内上线、红色表示超过一天。

注意：

- 不要解压后只上传 index.html，必须上传整个 ZIP。
- ZIP 根目录的 _worker.js 负责共享排行榜和两周冠军奖励，不能删除。
- 网站本体不需要 GitHub，也不需要手动往 KV 添加数据；只有首次启用实时好友对战时，需要双击对战包里的一键部署文件。
- v56 会继续使用现有账号、排行榜、聊天室、人物、兑换码、网站封锁和限量抢购记录的 LEADERBOARD KV，不会清空玩家进度，也不需要新建或重新绑定 KV。
- 本人点击首页右上角头像后，可以在「金币明细」查看起始余额、关卡拾取、通关奖励、兑换码、角色购买、账号升级、云青预约与后台礼物的每一笔增减和变动后余额。
- 金币明细只会通过已登录账号返回给本人，不会出现在排行榜、聊天室或其他玩家资料中；记录会跟随账号跨设备同步。
- v56 会保留已有金币明细；不会伪造旧版本中无法确认的历史来源。
- v56 继续防止刷新时把同一笔对战奖励、兑换码、限量人物购买或后台礼物重复计入余额。
- 金币余额新增云端版本保护：旧页面、旧设备或缓存中的过期余额不能覆盖管理员校正后的最新余额。
- 刷新网页恢复账号时改为只读，不再重复保存账号和排行榜；反复刷新不会再消耗多次 KV 写入额度。
- 大型账号的余额校正拆分为“账号余额”和“排行榜余额”两个独立小操作，避免 Cloudflare 1101 超时。
- 异常余额改为在后台通过“校正余额”单独处理，不会占用排行榜读取时间，也不会影响排行榜连接。
- 后台每位玩家新增“校正余额”按钮，可以准确设定金币，不必删除或重置账号。
- 后台赠送金币会立即增加玩家的云端余额并同步排行榜；玩家打开首页或刷新排行榜时会看到礼物到账弹窗，收到后可直接购买人物。
- 首页会为“新人物、限时优惠”等活动显示游戏化弹窗；每个活动每个账号只提示一次。以后新增活动时也会使用同一套提示方式。
- 第 1–5 关改为轻松入门，不会出现隐藏洞穴，飞机、乌鸦、落物、开洞与黑洞数量都已大幅减少。
- 第 1–10 关在没有进入洞穴时约 30–40 秒完成；第 11 关开始才明显加速并提高意外密度。
- 每个玩家会在第 6–10 关中随机遇到 1 个隐藏洞穴；同一账号的洞穴关卡保持一致，方便重新挑战。
- 游戏中间顶部会显示体力条；体力较低时灵敏度、加速和花式速度会下降，但仍保留足够跳跃能力。
- 每局结束后体力自动恢复满；人物价格越高通常越耐久。
- 特别活动人物贝贝已经下架；以前购买过的账号不会失去人物，仍可继续选择使用。
- 新人物元元将在 2026 年 7 月 27 日 10:00（新加坡时间）开抢，售价 999 金币，全站限量 3 份；重复点击或刷新不会重复扣款。

- 三次连跳的最后一次空中跳使用后，必须真正落地才能恢复；继续点击不会让人物无限停在空中。
- 第 3 关开始才会少量出现飞机，第 1–5 关每关最多 1 架；人物在空中撞到飞机会掉 1 滴血，不能踩掉飞机。
- 飞机会随机投放炸弹，地面会提前显示红色爆炸范围；爆炸附近的玩家掉半滴血。飞机与投弹会避开同时发生的密集警告，地面始终保留安全路线。
- 玩家输入名字后会立即加入排行榜，即使还没有完成一局也会显示。
- 排行榜会显示当前赛季所有已登记玩家，不再只显示前 10 名。
- 隐藏洞穴约 30 秒且没有金币；进入时生命立即回满，入口恢复安全地面并清除上一段未落下的意外。
- 洞穴入口前约 5 秒是绝对安全区：碰撞和坠落都不会扣血；意外坠落时人物会自动回到洞穴地面，离开安全区后才恢复正常伤害。
- 洞穴会在约 3.2 秒内动态地逐渐变暗，手电筒范围已扩大并提高亮度；前 5 秒不会出现洞穴裂缝或洞穴意外。

- 20 关使用 20 套与关卡标题对应的独立背景。
- 第二层的低矮树枝是真实碰撞障碍：站立从下面经过会受伤，必须按住下滑/↓蹲下，或跳到平台上方。
- 首页已简化为“挑战、角色、排行、聊天”四个入口；账号升级和兑换码收进“账号升级与兑换码”，原功能没有删除。
- 每个账号第一次进入时会提示“排行榜和聊天头像可以点击”；提示记录会跟随云端账号同步，不会在每台设备反复出现。

- 首页聊天气泡会显示未读消息数量；自己发送的消息不计入未读，打开聊天并成功读取后数字自动清零。
- 聊天已读时间会跟随云端账号同步，换设备登录不会把已经读过的消息再次算作未读；第一次升级到 v25 时旧消息会作为已读基准，不会突然显示大量旧消息。

六、v32 好友实时对战（如果以前部署过，也需要覆盖更新 Worker）

1. 解压 cloud-jumper-v32-battle-worker.zip。
2. Mac 双击里面的“一键部署实时对战.command”，按提示登录 Cloudflare 并部署。
3. 回到 Pages 项目 → 设置 → 绑定 → 添加 Durable Object namespace。
4. Variable name 必须填写：BATTLE_ROOMS（全部大写）。
5. 选择 cloud-jumper-battle 的 BattleRoom 命名空间，保存后重新部署 v56 网站 ZIP。
6. 更详细的逐步说明在对战压缩包里的“实时对战绑定说明.txt”。

v32 对战规则和操作：

- 首页有独立的“好友对战”入口，不会替换原来的单人关卡。
- 创建房间后可以复制 6 位房间码或邀请链接，也可以在排行榜/聊天点击玩家头像后直接邀请。
- 房主可以在轻松、标准、困难、疯狂四档中选择；切换难度会取消双方准备，避免误开局。
- 两位玩家都点“我准备好了”后自动开始 60 秒积分赛；普通金币 +1 分，大金币 +5 分，连续拾取会有小额连击加分。
- 人物会自动前进并逐渐加速，不用一直按住右键；← 可减速/后退，↑/空格跳跃，按住 ↓ 蹲下。
- 开局第一帧就会显示低透明度对手；距离太远时，屏幕边缘会显示他在前方或后方以及距离。
- 右下角大招每人每局只能使用 1 次，服务器随机选择“炸弹”或“飞机轰炸”，命中对手后掉 1 滴血。
- 对战生命耗尽不会结束整局：人物在最近位置恢复、生命回满并扣 8 积分，然后继续比赛。
- 对战拾取的金币每 4 枚兑换 1 枚账号金币；结算会写入本人金币明细。
- 对战场次、胜场、最佳分和对战积分会进入“对战排名”，并与单人关卡成绩一起计入“综合排名”。
- 好友邀请和对战位置使用 Durable Object WebSocket；原账号、聊天和排行榜仍然使用 LEADERBOARD KV，两种绑定都要保留。
- 排行榜和聊天里的挑战者现在可以真正接受邀请、进入房间、显示实时半透明位置、使用大招并参加正式结算。
- 挑战者也会偶尔主动向已上线的真人玩家发来邀请；真人接受后仍可选择难度，不接受不会影响账号或单人进度。

七、v56 排行榜自愈与上下文智能聊天

- 主页面重新统一为更简洁的高级界面：深色挑战主卡、清楚的四个功能入口、精简玩家概况和更一致的留白。
- 商店、排行榜、关卡、聊天、登录与个人资料沿用全部原功能，只统一卡片、按钮、颜色和手机响应式尺寸。
- 游戏相机改为按实际帧间隔平滑移动，60Hz、90Hz 和 120Hz 设备的跟随速度更一致。
- 卡顿时会自动把单帧更新拆成多个小步，减少高速时穿过障碍、画面跳动和碰撞不稳定。
- 高价人物会按原价等级自动出现不同强度的隐藏光效、落地光圈、轨迹与高阶残影；商店不会提前说明这些彩蛋。
- 手机会按设备能力限制画布像素倍率和粒子上限，在保持清晰的同时减少发热与掉帧。
- 赛季切换后会保留全部注册账号；还没参加新赛季的玩家显示“已登记 · 尚未挑战”，不会只剩刚上线的玩家和挑战者。

- 封锁时管理后台不会被关闭，管理员可随时进入并立即解除封锁。

八、可选 OpenAI Responses API（响应接口）接入

1. Pages 项目 →「设置」→「变量和机密」→ 添加加密机密 OPENAI_API_KEY。
2. 只在 Cloudflare 后台粘贴自己的 API 密钥，不要把密钥写进网页、压缩包、GitHub 或聊天消息。
3. 可添加 OPENAI_MODEL=gpt-5.6-terra。
4. 需要实时天气/新闻时，再添加 OPENAI_WEB_SEARCH=true。
5. 重新部署后访问 /api/health；openAIConfigured:true 表示 Cloudflare 已读取密钥。

没有配置密钥时游戏自动使用本地回复；接口失败或超过约 8.5 秒也会自动回退，不会阻塞玩家消息。

九、v56 Gemini 玩家行为与回复节奏

- 普通“@挑战者 问题”仍会优先使用 Gemini，但会像真人一样等待约 18–65 秒再出现，不再每次秒回。

- 没有 @任何挑战者时，角色只会低概率参与适合的话题，并会等待更久，避免抢答每一条真人消息。
- 五个挑战者各有固定语气和不同研究偏好，会重点讨论路线、落点、跳跃节奏、人物体力、金币取舍、意外规律与对战验证。
- Gemini 会读取最近可见的真人和挑战者对话，用于理解“刚才那条路线”等上下文，但最后一条玩家消息始终是主问题。
- 日常、足球、学习、天气等生活话题可以自然交流，但只在玩家先提起时参与，不会强行把每句话都转回游戏。
- 对战邀请只会在明确聊到 PK、路线比较或玩家近期参与游戏讨论时低频出现；仍需玩家回复“同意”后才生成可点击邀请。
- 当前问题不会再同时出现在“最近对话”和“必须回答的消息”里，减少模型把聊天对象和问题弄混。
- 回复发出前会检查是否与玩家问题相关；出现“刚上线、准备玩第 5 关、先学路线”等无关套话时会自动拦截。
- 真人玩家发消息前后，预排的日常闲聊会让路 2 分钟，避免自动消息紧跟在人类问题后面造成“牛头不对马嘴”。
- 先在聊天室使用一次“@小砚 admin：介绍 Gemini”，再打开 /api/health 查看 geminiLastCheck。ok:true、status:200 说明 Gemini 已真实调用成功；失败时会显示不含密钥的简短原因。

十、推荐接入 Gemini 免费回复

1. 浏览器打开 https://aistudio.google.com/apikey，并登录 Google 账号。
2. 点击「Create API key（创建 API 密钥）」。
3. 选择一个现有 Google Cloud 项目；没有项目就按页面提示创建新项目。
4. 复制生成的 API Key，不要把它发给任何人，也不要写进 ZIP 或 GitHub。
5. 打开 Cloudflare → Workers 和 Pages → leo-mario →「设置」→「变量和机密」。
6. 点击「添加」，类型选择「密钥/加密机密」，名称填写 GEMINI_API_KEY。
7. 值粘贴 Gemini API Key，保存。
8. 不需要设置模型变量；v56 默认使用 gemini-3.6-flash，并自动备用 gemini-3.5-flash 和 gemini-3.5-flash-lite。
9. 回到「部署」并重新部署最新 v56，变量才会进入线上版本。
10. 打开 https://你的游戏网址/api/health，看到 geminiConfigured:true 表示密钥已连接。
11. 在聊天室发送“@小砚 admin：介绍 Gemini”，等回复后刷新 /api/health。
12. geminiLastCheck 里面出现 ok:true 和 status:200，表示网站已真正调用 Gemini。

- v56 会先用 Gemini 3.6 Flash；失败时自动切换 3.5 Flash、3.5 Flash-Lite，全部失败才使用本地安全回复。OpenAI 变量如果已删除，不需要重新添加。
- “好、嗯、知道了”会自然回复，不再显示“我看到你说的是……”。
- “介绍 OpenAI”“介绍 Gemini”等基础问题即使网络接口失败，也会直接给出基础答案。
- Gemini 免费层有使用次数限制；达到限制时游戏会自动使用下一层备用，不影响聊天室发送。

十一、v56 账号管理员与后台 Gemini

1. 先用最高管理员密码 2026 打开 https://你的游戏网址/admin/。
2. 点击「管理员」，搜索玩家账号并点击「设为管理员」。
3. 被授权玩家正常登录游戏账号后，再打开 /admin/ 会自动进入，不需要知道最高管理员密码。
4. 管理员可继续安排其他管理员；普通管理员不能取消自己的权限，最高管理员始终可以取消任何账号权限。
5. 管理员在公共聊天室会显示金色「管理员」标签；长按任意消息会自动选中，再点击其他消息即可多选并永久删除。普通玩家不会收到管理字段，也看不到管理工具；长按只能撤回本人 5 分钟内的消息并保留撤回占位。
6. 后台最后一个「AI 助手」页面使用现有 GEMINI_API_KEY。对话只保留在当前浏览器页面，不写入公共聊天室，也不会自动修改玩家数据。
7. 管理员自己的个人资料会出现「进入管理后台」按钮。若刚授权尚未出现，刷新一次排行榜或重新打开网站即可。
